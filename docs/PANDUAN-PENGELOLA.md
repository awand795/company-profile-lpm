# Panduan Pengelola Situs Master Truck (untuk orang awam)

Panduan singkat memakai Panel Pengelola WordPress (`/wp-admin/`).
Masuk dengan akun pengelola (bila lupa kata sandi, pakai tautan
"Lupa kata sandi?" di halaman masuk).

## 1. Ganti teks
1. Di Dasbor, klik **Edit Beranda** (atau menu **Beranda** di kiri).
2. Klik teks yang ingin diubah langsung di halaman, ketik teks baru.
3. Klik tombol hijau **Update** di bawah kiri.
4. Buka alamat situs untuk memastikan tampilan berubah.

## 2. Ganti foto
1. Di Dasbor, klik **Ganti Foto** (menu **Media**).
2. Klik **Tambah Baru**, pilih foto dari komputer, tunggu sampai selesai.
3. Buka **Edit Beranda**, klik foto yang ingin diganti, pilih foto baru
   di panel kiri, lalu klik **Update**.

## 3. Ubah nomor WhatsApp
1. Buka **Edit Beranda**.
2. Cari tombol **Chat WhatsApp** (bagian Derek 24 Jam / Tentang Kami).
3. Klik tombol, di panel kiri ubah kolom **Link** dengan format:
   `https://wa.me/62XXXXXXXXXX?text=Halo`
   (ganti `62XXXXXXXXXX` dengan nomor tujuan, tanpa spasi/tanda +).
4. Klik **Update**.

## 4. Bila tampilan beranda rusak/berantakan
1. Di Dasbor, pada kartu **Status Situs**, klik **Muat Ulang CSS Elementor**.
2. Tunggu, lalu muat ulang halaman situs (`Ctrl+R`).
3. Bila masih rusak, hubungi pengembang (jangan mengubah menu
   **Plugin** atau **Peralatan** tanpa didampingi).

## 5. Menu "Lanjutan"
Menu di kiri hanya menampilkan yang sering dipakai. Bila butuh menu
lengkap WordPress: buka **Pengguna → Profil Anda**, centang
**Tampilkan semua menu WordPress**, simpan.
